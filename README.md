# RePC Chile

Red comunitaria para donar, reacondicionar, certificar y redistribuir computadores a estudiantes.

## MVP

Flask + SQLAlchemy. Incluye flujo de colegios nodo, inventario, reparaciones, certificación, cadena de custodia y selección de equipos por estudiantes.

## Render

Build: `pip install -r requirements.txt`

Start: `gunicorn app:app`
